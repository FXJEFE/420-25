❓ TROUBLESHOOTING:

Q: EA doesn't appear in Navigator
A: Run sync script again:
   ./sync_to_wine_mt5.sh
   Then restart MT5 (F5 or Terminal → Restart)

Q: Wine paths don't exist
A: Check if MT5 is installed and terminals exist:
   ls ~/.wine/drive_c/Program\ Files/MetaTrader\ 5/
   If missing, install MT5 in Wine first

Q: Include files not found errors
A: Ensure .mqh files were copied:
   ls ~/.wine/drive_c/users/LarryLocal/AppData/Roaming/MetaQuotes/Terminal/*/MQL5/Include/
   Run sync script: ./sync_to_wine_mt5.sh

Q: Compiled .ex5 file has wrong checksum
A: Check DEPLOYMENT_MANIFEST.json for expected hash
   Delete the .ex5 file and recompile in MetaEditor

Q: "File not found" in EA logs
A: EA can't find include file or CSV
   Check that .mqh files are in Include folder
   Check CSV file path in EA code
